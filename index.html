    HOW TO EXPLORE

    끌고, 발견하고, 연결하세요.

    1. 초록색 포인터를 원하는 동네로 끌어보세요.
    2. 잠깐 멈추면 주변 장소가 날개처럼 펼쳐집니다.
    3. 장소 이름 위에서 손을 떼거나 이름을 눌러 추가하세요.
    4. 추가한 목적지를 길게 누르면 다음 장소를 연결합니다.
    5. 경로를 선택하고 GPS 안내를 시작하세요.

    위치·카메라·방향 센서는 기능을 사용할 때 권한을 요청합니다. 동선은 이 기기에 저장됩니다. 장소 조회와 경로 계산 시 선택한 좌표가 해당 지도 서비스로 전송됩니다.

    장소: OpenStreetMap 등록 정보(누락 가능). 경로: OSRM 차량 경로. 카메라는 GPS·나침반 기반 방향 안내이며 도로면에 고정되는 정밀 AR은 아닙니다.
