# 길찾기한눈

포인터를 끌어 주변 장소를 발견하고, 여러 목적지를 연결하는 지도 웹 앱.

- 운영 주소: https://softm.github.io/gilchatgihannun/
- Android (Private): https://github.com/softm/gilchatgihannun.android
- 서버 설치 및 API 키 없이 첫 실행 가능. 장소·지도·경로 조회에는 인터넷 연결이 필요합니다.

## 실행

```sh
npm run dev
# http://localhost:5173
npm test
npm run check
```

GitHub Pages에는 저장소 루트의 정적 파일을 배포합니다. `Settings → Pages → Source: GitHub Actions`를 선택하면 포함된 워크플로가 테스트 후 게시합니다. 기존 main/root 방식으로 설정돼 있어도 루트의 index.html을 사용할 수 있습니다.

## 사용 흐름

1. 위치 권한을 허용하거나 지도에서 출발할 지점을 누른 뒤 **여기서 출발**을 선택합니다.
2. 초록 포인터를 끌고 잠깐 멈추면 그 위치 주변의 장소를 날개 메뉴로 조회합니다.
3. 장소 위에서 손을 떼거나 이름을 눌러 목적지를 추가합니다. 이름을 모르면 **＋ 목적지 추가**도 가능합니다.
4. 목적지 마커 또는 목록을 450ms 길게 누른 뒤 끌면 해당 장소에서 다음 탐색을 시작합니다. 목록 ↑↓로 방문 순서를 바꿀 수 있습니다.
5. 경로 탐색 → 후보 선택 → 안내 시작. 방문 순서 최적화는 출발지와 마지막 목적지를 유지합니다.
6. 레이더 HUD / 카메라 / 지도 모드를 전환합니다. Android에서는 다른 앱 위 HUD도 제공합니다.

## 구현 범위

| 기능 | 상태 |
|---|---|
| 현재 위치, 드래그 포인터, 날개 메뉴, 업종·반경 필터 | 구현 |
| 목적지 최대 12개, 삭제·순서 변경, 기기 내 저장 | 구현 |
| 차량 경로, 제공되는 대안 경로, 방문 순서 최적화 | 구현 |
| GPS 위치·이동 방향·이동 궤적, 근접 도착, 이탈 후 재탐색 | 구현 / 실제 주행 검증 필요 |
| 기울기 0°/45°/60°, 건물 높이 표시 | MapLibre + 지도 데이터 지원 범위 |
| WebGL 미지원 기기 | Leaflet 2D 자동 전환 |
| 레이더 HUD | 구현 |
| 카메라 방향 안내 | 카메라 + GPS/나침반 기반 / 정밀 AR 아님 |
| ARCore 지리 앵커, 차로·도로면에 고정되는 AR | 미구현 |
| 음성 내비게이션, 실시간 교통·통행료, 보행·대중교통 경로 | 미구현 |

최적화 결과는 OSRM Trip의 방문 순서 결과입니다. 전역 최적해나 실시간 최단시간을 보장하지 않습니다. 대안 경로가 없으면 임의의 경로를 만들지 않고 실제 반환된 한 경로만 표시합니다.

## 데이터와 외부 서비스

- 벡터 지도: [OpenFreeMap](https://openfreemap.org/) / MapLibre GL JS 5.6.2.
- 2D 대체 지도: OpenStreetMap 표준 타일 / Leaflet 1.9.4. 공개 타일은 서비스 정책과 부하에 따라 제한될 수 있습니다.
- 주변 장소: Overpass API(기본 서버 실패 시 Private.coffee 공개 인스턴스 1회 대체 조회), OpenStreetMap 등록 데이터. 이름·종류·좌표 기준 최대 100개 조회 후 반경 내 결과를 표시하며, 국내 상점이 모두 등록되어 있지는 않습니다. 영업 여부·리뷰·사진을 추정해 만들지 않습니다.
- 경로: OSRM 공개 차량 라우팅 서버. 대안 수는 서버가 결정합니다. 공개 서비스에는 SLA가 없으므로 상용 운영 전에 전용 지도·장소·경로 공급자 또는 자체 서버를 연결하세요.
- 공급자 주소는 `providers.js`, 2D 지도 공급자는 `raster-map.js`에서 관리합니다. 비밀키는 정적 웹 저장소에 추가하지 않습니다.

선택한 지도 좌표는 장소 조회 서버로, 출발지·목적지는 경로 서버로 전송됩니다. 현재 지도 영역은 지도 공급자에게 요청됩니다. 동선과 이동 궤적은 localStorage에만 저장하며, **사용 방법 → 이 기기의 동선·이동 기록 삭제**로 지울 수 있습니다. 카메라 영상은 서버로 업로드하지 않습니다.

## 검증

- Node 테스트 18개: 거리·방향 경계, 손상된 저장 값, 이탈 거리, 메뉴 화면 경계, 회전 안내, 장소 파싱, 최적화 순서, 경로 실패 처리.
- 브라우저: 장소 조회(광명 지도 기준 실제 등록 장소), 동선 추가, 차량 경로 결과, WebGL 미지원 2D 전환 확인.
- GitHub Pages 운영 주소에서 2D 지도 배경 타일과 조작 버튼 표시 확인. WebGL 기기의 벡터 지도, 실기기 위치·카메라·방향은 별도 검증 대상입니다.

## 라이선스

앱 소스에 별도 오픈소스 이용 허락을 부여하지 않았습니다. 공개 열람과 소스 이용 허락은 별개입니다. 동봉 라이브러리 라이선스는 `vendor/`에 보존합니다. 지도 데이터·타일·라벨의 저작권 표시는 제거하지 않습니다.

## Playwright 수정 검증 (2026-10-31)

브라우저 시나리오 13개와 Node 회귀 테스트 18개를 통과했습니다. 수동 출발지 복원, 다음 목적지 ID 충돌, 드래그 선택, HUD 상태, 반응형 메뉴와 배포 캐시를 수정했습니다. [검증 보고서](docs/PLAYWRIGHT_TEST_REPORT.md)에서 범위와 외부 장소 서버의 가용성 한계를 확인할 수 있습니다.

## 포인터와 선택 메뉴 개선 (2026-10-31)

탐색 포인터를 지도 렌더러 밖의 독립 레이어에 표시하고 지도 이동·확대·목록 크기 변경 시 사용 가능한 지도 영역 안에 유지합니다. 원래 지점이 화면 밖이면 지도 탐색을 방해하지 않고 가장자리의 포인터를 끌어 새 위치를 탐색할 수 있습니다. 실제 GPS 위치는 별도의 파란 마커로 유지합니다.

원형 메뉴 중앙의 ×를 제거하고 **＋ 목적지 추가**를 주요 동작으로 표시합니다. **닫기**와 **출발지 변경**은 중앙 추가 버튼 주변의 작은 보조 동작입니다.
